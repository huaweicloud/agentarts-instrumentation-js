# DeepSeek Harness（DSH）插件接入指导

> **接入分类**：编码智能体
> **官方适配**：本接入方式为官方适配
> **步骤名称**：安装步骤为「安装插件」，启动步骤为「重启 DSH」
> **插件版本**：1.0.0

本文介绍如何将 DeepSeek Harness（DSH）接入华为云 AgentArts 观测服务，实现调用链追踪和业务指标监控。

整个接入分三步：

| 步骤 | 做什么 | 说明 |
|---|---|---|
| **步骤一** | 安装插件 | 通过插件市场或插件安装命令 |
| **步骤二** | 配置接入信息 | 运行配置脚本，或手动编辑配置文件 |
| **步骤三** | 重启 DSH | 重启后配置生效 |

> 安装与配置是**两个独立步骤**：插件安装后不会自动上报，必须完成步骤二写入接入信息。

## 版本要求

| 项目 | 要求 |
|---|---|
| DSH | **>= 0.2.1-rc.2** |
| 观测插件 | 1.0.0 |
| 操作系统 | Windows 10 及以上 / Linux / macOS |
| 配置脚本运行环境 | Windows：PowerShell **5.1 及以上**；Linux / macOS：**bash** |
| 网络 | 可访问 AgentArts 上报端点（默认 HTTPS 443） |

> DSH 自带 Node.js 运行时，无需单独安装 Node.js。上报端点必须网络可达，跨境或弱网环境请先确认链路质量。

> **计费说明**
>
> - 在 AgentArts 观测界面查看数据不收费。
> - 数据上报会产生费用：调用链上报到 APM（[APM 计费说明](https://support.huaweicloud.com/price-apm2/apm_07_0019.html)），
>   指标上报到 AOM（[AOM 计费说明](https://support.huaweicloud.com/price-aom2/aom_07_0004.html)）。
> - APM 与 AOM 均为按需计费，有一定免费额度，超出后按实际使用量收费。

## 第 0 步：确认 DSH 形态

DSH 有 desktop 与 web 两种形态，**安装方式与重启方式不同**，请先对号入座。

| 判断依据 | 说明 |
|---|---|
| 启动方式 | 双击桌面客户端启动 → **desktop**；命令行执行 `dsh web` 启动 → **web** |
| 环境变量 | 在启动 DSH 的终端执行 `echo $env:DSH_PROFILE`（PowerShell）或 `echo $DSH_PROFILE`（bash） |
| profile 目录 | `~/.dsh/profiles/desktop` 或 `~/.dsh/profiles/web` 哪个存在 |

| | desktop 形态 | web 形态 |
|---|---|---|
| profile 名 | `desktop` | `web` |
| profile 管理方 | DSH 桌面客户端 | `dsh web` 命令进程 |
| 安装方式 | 客户端内的插件市场，或插件页添加 | 插件安装命令 |
| 配置方式 | 相同（同一份配置文件） | 相同 |
| 重启方式 | 完全退出客户端后重新打开 | 终止并重新执行 `dsh web` |

## 步骤一：安装插件

插件包名 `huaweicloud-agentarts-observation-dsh-plugin`，产物为
`huaweicloud-agentarts-observation-dsh-plugin-1.0.0.tgz`。

### Windows（PowerShell）

```powershell
# web 形态：从本地产物安装
dsh plugin --profile web add "file:<产物目录>\huaweicloud-agentarts-observation-dsh-plugin-1.0.0.tgz"

# web 形态：从 Git 仓库安装（固定 commit）
dsh plugin --profile web add "git+https://github.com/huaweicloud/agentarts-instrumentation-js.git#<commit>&path:/agentarts-instrumentation-dsh"
```

### Linux（bash）

```bash
# web 形态：从本地产物安装
dsh plugin --profile web add "file:<产物目录>/huaweicloud-agentarts-observation-dsh-plugin-1.0.0.tgz"

# web 形态：从 Git 仓库安装（固定 commit）
dsh plugin --profile web add "git+https://github.com/huaweicloud/agentarts-instrumentation-js.git#<commit>&path:/agentarts-instrumentation-dsh"
```

> 包发布到 npm 仓库后，上述命令可简化为
> `dsh plugin --profile web add huaweicloud-agentarts-observation-dsh-plugin`。

### desktop 形态

desktop profile 由桌面客户端独占管理，命令行安装会被拒绝。请在客户端内安装：

1. 打开 DSH，进入 **Plugins** 页面。
2. 切换到 **Discover**（插件市场）搜索并安装本插件；或在 **Add plugin** 中添加。

### 确认安装结果

以下命令适用于两种形态，用于确认插件已注册（把 `web` 换成实际 profile 名）：

**Windows（PowerShell）**

```powershell
Get-Content "$env:USERPROFILE\.dsh\profiles\web\package.json" | Select-String "huaweicloud"
```

**Linux（bash）**

```bash
grep -i huaweicloud ~/.dsh/profiles/web/package.json
```

`dsh.profile.bundles` 中应出现 `huaweicloud-agentarts-observation-dsh-plugin`。

## 步骤二：配置接入信息

### 先获取参数

1. 登录 [AgentArts 智能体平台](https://console.huaweicloud.com/agentarts/)。
2. 左侧导航选择 **观测与优化 > 观测**。
3. 单击 **接入智能体**，填写名称并选择智能体类型，创建 DSH 智能体，页面会给出各配置参数。

| 参数 | 说明 |
|---|---|
| 智能体 ID | AgentArts 智能体资源 ID |
| 账号 Domain ID | 账号 domain ID |
| 项目 ID | 华为云项目 ID |
| APM 上报地址 | 形如 `https://apm-access.<region>.myhuaweicloud.com` |
| APM Token | 调用链上报凭证 |
| AOM 上报地址 | 形如 `https://aom-access.<region>.myhuaweicloud.com` |
| AOM Access Code | 指标上报凭证 |
| AOM Prometheus ID | 指标实例标识 |

### Windows（PowerShell）

```powershell
# 临时放开脚本执行权限（仅当前窗口有效，不改系统策略）
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

# 凭据走环境变量，避免进入命令历史
$env:DSH_AGENTARTS_APM_TOKEN = "<apm-token>"
$env:DSH_AGENTARTS_AOM_ACCESS_CODE = "<aom-access-code>"

.\dsh-agentarts-plugin.ps1 `
  -AgentId <id> `
  -DomainId <id> `
  -ProjectId <id> `
  -Endpoint https://apm-access.<region>.myhuaweicloud.com `
  -AomEndpoint https://aom-access.<region>.myhuaweicloud.com `
  -AomPrometheusId <prometheus-id> `
  -AgentName <agent-name> `
  -CaptureMessageContent true
```

### Linux（bash）

```bash
export DSH_AGENTARTS_APM_TOKEN="<apm-token>"
export DSH_AGENTARTS_AOM_ACCESS_CODE="<aom-access-code>"

./dsh-agentarts-plugin.sh \
  --agent-id <id> \
  --domain-id <id> \
  --project-id <id> \
  --endpoint https://apm-access.<region>.myhuaweicloud.com \
  --aom-endpoint https://aom-access.<region>.myhuaweicloud.com \
  --aom-prometheus-id <prometheus-id> \
  --agent-name <agent-name> \
  --capture-message-content true
```

`-CaptureMessageContent`（bash 为 `--capture-message-content`）取值为 `true` 或 `false`：

- `true`：上报输入输出等会话内容（默认）
- `false`：只上报调用链结构与性能指标，不含消息、系统提示词、工具参数与结果文本

该开关属 `features`，**热生效**，无需重启 DSH；也可用简写 `-NoMessageContent` / `--no-message-content` 关闭。

> **例外**：为了保留技能维度的观测，关闭内容采集时 `skill` 工具的调用参数**仍会上报，但只保留技能名**
> （如 `{"name":"dsh-doc"}`），其余字段一律丢弃；其他工具的参数完全不采集。

### 手动配置（可选）

不运行脚本时，可直接编辑配置文件（**与 profile 无关，desktop 与 web 共用同一份**）：

```
Windows : %USERPROFILE%\.dsh\plugins\huaweicloud-agentarts-observation-dsh-plugin\config.json
Linux   : ~/.dsh/plugins/huaweicloud-agentarts-observation-dsh-plugin/config.json
```

最小可用内容见 [config.example.json](../config.example.json) 中的 `otel` 段。

### 参数说明

- 必填：智能体 ID、APM 上报地址、APM Token
- 启用 AOM 指标时还需：项目 ID、AOM 上报地址、Access Code、Prometheus ID

| 参数（PowerShell / bash） | 是否必填 | 说明 |
|---|---|---|
| `-AgentId` / `--agent-id` | 是 | 智能体 ID |
| `-DomainId` / `--domain-id` | 否 | 账号 domain ID |
| `-ProjectId` / `--project-id` | 启用 AOM 时必填 | 华为云项目 ID |
| `-Endpoint` / `--endpoint` | 是 | APM 数据上报地址 |
| `-Token` / `--token` | 是 | APM 接入凭证（建议走环境变量） |
| `-AomEndpoint` / `--aom-endpoint` | 启用 AOM 时必填 | AOM 数据上报地址 |
| `-AomAccessCode` / `--aom-access-code` | 启用 AOM 时必填 | AOM 接入凭证（建议走环境变量） |
| `-AomPrometheusId` / `--aom-prometheus-id` | 启用 AOM 时必填 | AOM Prometheus 实例 ID |
| `-AgentName` / `--agent-name` | 否 | 智能体名称，写入 `gen_ai.agent.name` |
| `-CaptureMessageContent` / `--capture-message-content` | 否 | 是否上报会话内容，`true` / `false` |
| `-NoMessageContent` / `--no-message-content` | 否 | 上一条的简写，等价于关闭内容采集 |
| `-LinkSubagentTrace` / `--link-subagent-trace` | 否 | 子 agent trace 是否串联到父 trace |

> 资源类型固定上报为 `agent`，资源版本自动取运行中的 DSH 版本，均无需配置。
> `-CaptureMessageContent` / `-LinkSubagentTrace` **不传时保持配置文件中的现有值**，不会被重置。

## 步骤三：重启 DSH

**这一步不能跳过**，安装与配置的改动都在重启后生效。

### Windows（PowerShell）

```powershell
# web 形态：在运行 dsh web 的窗口按 Ctrl+C 终止，然后重新启动
dsh web

# desktop 形态：完全退出客户端（含系统托盘）后重新打开
#   Get-Process "DeepSeek Harness" | Stop-Process    # 如托盘无法退出，可用此命令
```

### Linux（bash）

```bash
# web 形态：Ctrl+C 终止后重新启动
dsh web

# desktop 形态：退出应用后重新打开
#   pkill -f "DeepSeek Harness" || true
```

### 为什么必须重启

- 新安装的插件需要重启加载；替换已安装的包同样需要，以加载新的模块代。
- `otel` 段（端点、开关、凭证）在插件加载时绑定上报管线，**不支持热更新**；
  而 `features.*` 与 `agent_name` 支持热生效，改完无需重启。

## 验证数据上报

| 数据类型 | 何时产生 | 期望日志 |
|---|---|---|
| 调用链（trace） | **每轮对话结束后**批量导出 | `APM (Traces) exporting` → `export SUCCESS` |
| 指标（metric） | 每 **60 秒**周期导出 | `AOM (Metrics) exporting` → `export SUCCESS` |

日志路径：

```
Windows : %USERPROFILE%\.dsh\plugins\huaweicloud-agentarts-observation-dsh-plugin\data\logs\plugin-YYYY-MM-DD.log
Linux   : ~/.dsh/plugins/huaweicloud-agentarts-observation-dsh-plugin/data/logs/plugin-YYYY-MM-DD.log
```

加载成功的标志：

```
[agentarts-dsh] plugin starting, version: 1.0.0
[agentarts-dsh] config loaded: {... "apmEnabled":true, "aomEnabled":true}
[agentarts-dsh] APM (Traces) initialized {...}
[agentarts-dsh] AOM (Metrics) initialized {...}
[agentarts-dsh] plugin loaded successfully
```

若日志中完全没有 AOM 的 `exporting` 行：说明该周期内没有记录到指标——指标在对话结束时才记录，
且导出器在"本周期无指标"时会静默跳过。

## 查看监控数据

1. 登录 [AgentArts 智能体平台](https://console.huaweicloud.com/agentarts/)。
2. 左侧导航选择 **观测与优化 > 观测**。
3. 找到已接入的智能体，单击名称进入详情。

**指标分析**：Tokens 消耗、模型调用次数与平均耗时、调用成功率、会话数、响应成功率、工具/技能统计。

**调用链分析**：span 层级 `invoke_agent` → `react step` → `chat <model>` / `execute_tool <tool>`，
可查看各节点耗时与属性（Token 用量、缓存读写、TTFT、工具参数与结果等），以及状态
（成功为 `STATUS_CODE_OK`，失败为 `STATUS_CODE_ERROR` 并带原因）。

**会话分析**：对话上下文、模型响应耗时、Token 消耗、异常定位。

## 运行配置说明

| 字段 | 说明 |
|---|---|
| `enabled` | 总开关，`false` 时不采集 |
| `otel.agentarts_agentops_otel_agent_apm_enable` | 是否上报调用链 |
| `otel.agentarts_agentops_otel_agent_aom_enable` | 是否上报指标 |
| `features.captureMessageContent` | 是否采集消息内容（默认 `true`） |
| `features.linkSubagentTrace` | 是否把子 agent 串联到父 trace（默认 `true`） |
| `features.debug` | 是否输出 DEBUG 明细日志 |
| `features.logRetentionDays` | 日志保留天数（默认 14，`0` 关闭清理） |
| `user.id` | 用户标识，为空时取主机名 |

**热更新规则**：`features.*` 与 `agent_name` 修改后无需重启；
`otel`、`enabled`、`outputDir`、`user.id` 修改后需要重启。

## 常见问题

**装完插件后没有数据**

按三步排查：步骤一是否安装成功（`dsh.profile.bundles` 是否含插件名）→ 步骤二是否完成
（配置文件存在且 `otel` 段有值）→ 步骤三是否重启。

**desktop 形态下执行 `dsh plugin --profile desktop add` 被拒绝**

desktop profile 由桌面客户端独占管理，属预期行为。请在客户端内的插件市场安装。

**插件装到了错误的 profile**

命令行的 `--profile` 要填实际运行的那个。桌面客户端对应 `desktop`，`dsh web` 启动的对应 `web`。

**Windows 提示"无法加载文件，因为在此系统上禁止运行脚本"**

在同一窗口执行 `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`；
若脚本来自网络下载，还需 `Unblock-File .\dsh-agentarts-plugin.ps1` 解除网络标记。

**调用链无数据**

1. 确认 `agentarts_agentops_otel_agent_apm_enable` 为 `true`，APM 地址与 Token 已配置。
2. 确认本机可访问 APM 端点（`Test-NetConnection <host> -Port 443`）。
3. 确认已完成至少一轮对话（对话结束后才导出）。
4. 查看日志是否有 `APM (Traces) export SUCCESS`。

**指标无数据**

1. 确认 `agentarts_agentops_otel_agent_aom_enable` 为 `true`。
2. 确认项目 ID、AOM 地址、Access Code、Prometheus ID 四项齐全。
3. 指标为 60 秒周期导出，等待一个周期再查。
4. 若完全没有 `AOM (Metrics) exporting` 行，说明该周期没有指标（无对话活动），属正常。

**AOM 认证失败**

日志出现 `UNAUTHENTICATED` 或 `accesscode does not match the projectId`：
确认 Access Code 与项目 ID 属于同一账号、同一实例，Prometheus ID 正确；
登录 AgentArts 重新获取参数后重跑配置脚本并重启。

**日志出现 `DEADLINE_EXCEEDED` / `UNAVAILABLE`**

弱网下首次建链可能超时。插件已内置 30 秒超时与最多 3 次重试（退避 2s/8s），
看到 `export failed, retrying` 后跟 `SUCCESS` 属正常重试，数据不会丢失。

**看不到 LLM 输入/输出内容**

确认 `features.captureMessageContent` 为 `true`。

**子 agent 与父对话不在同一条调用链**

子 agent 以父 turn 进行中的 root span 为父；若子 agent 在父 turn 结束后才启动，
会形成独立 trace。此时仍可按 span 上的 `dsh.session.parent_id` 属性过滤聚合。

**工具 span 上没有 `gen_ai.tool.description`**

工具描述来自 LLM 请求携带的工具定义；若该工具不在请求的 tools 列表中，则不上报该属性。

## 安全与隐私

插件会把 DSH 运行时数据发送到 AgentArts，**默认会上报会话内容**：

| 类别 | 字段 |
|---|---|
| 会话内容 | `gen_ai.input.messages`、`gen_ai.output.messages` |
| 系统提示词 | `gen_ai.system_instructions` |
| 工具调用 | `gen_ai.tool.call.arguments`、`gen_ai.tool.call.result` |
| 设备标识 | `user.id`（未配置时取主机名） |
| 会话标识 | `gen_ai.session.id` |

若会话中可能出现敏感信息，把 `features.captureMessageContent` 设为 `false`（热生效），
或执行 `-NoMessageContent` / `--no-message-content`。此后仍上报调用链结构与性能指标，
但不含上述内容文本（技能名例外，见步骤二说明）。

凭据以明文存放于 `config.json`。配置脚本会自动收紧权限（Windows 移除继承、仅当前用户/
SYSTEM/Administrators；Linux/macOS 为 `chmod 600`），并对历史备份做同样处理，最多保留 5 份。
更完整的安全说明见 [SECURITY-NOTES.md](../SECURITY-NOTES.md)。

## 卸载

插件卸载由 DSH 自身完成：

**Windows（PowerShell）**

```powershell
dsh plugin --profile web remove huaweicloud-agentarts-observation-dsh-plugin
```

**Linux（bash）**

```bash
dsh plugin --profile web remove huaweicloud-agentarts-observation-dsh-plugin
```

desktop 形态请在客户端 **Plugins** 页卸载。配置文件不随卸载删除，如需清理请手动删除
`~/.dsh/plugins/huaweicloud-agentarts-observation-dsh-plugin/`。

## 限制说明

- 调用链在**每轮对话结束后**批量导出，对话进行中不会实时出现。
- 指标为 **60 秒周期**导出。
- 父 turn 结束后才启动的子 agent 不会串联到父 trace。
- 配置为**全局共享**：desktop 与 web 两个 profile 若都装了本插件，会读取同一份 `config.json`。
- 上报端点必须网络可达；跨境或弱网环境请先确认链路质量。
