# DeepSeek Harness（DSH）插件接入指导

本文介绍如何将 DeepSeek Harness 接入华为云 AgentArts 观测服务，实现调用链追踪和业务指标监控。

**快速入门：**

前提：本机已安装 DeepSeek Harness（DSH），并可在终端使用 `dsh` 命令或已运行桌面客户端。

1. 在 AgentArts 平台创建 DSH 智能体，获取接入参数。
2. 执行安装脚本，或在 DSH 插件界面安装插件并完成配置。
3. 重启 DSH，触发一轮会话，在 AgentArts 观测页面查看数据。

详细步骤见下方[接入步骤](#接入步骤)。

## 前提条件

- 已安装 DeepSeek Harness（桌面客户端或 CLI），DSH 版本满足 `^0.2.1-rc.2`
- 可访问 AgentArts 上报端点（默认 HTTPS 443）
- 执行安装脚本需要：
  - Windows：PowerShell 5.1 及以上
  - Linux / macOS：bash

> **计费说明**
>
> - 在 AgentArts 观测界面查看数据不收费。
> - 数据上报会产生费用：
>   - 调用链上报到 APM（应用性能管理服务），费用明细请参考 [APM 计费说明](https://support.huaweicloud.com/price-apm2/apm_07_0019.html)。
>   - 指标上报到 AOM（应用运维管理服务），费用明细请参考 [AOM 计费说明](https://support.huaweicloud.com/price-aom2/aom_07_0004.html)。
> - AOM 和 APM 均为按需计费，并有一定免费额度，超出后按实际使用量收费。

## 工作原理

DSH 是 DeepSeek Harness 运行时，提供会话、多轮对话、模型调用与工具调用等能力。

AgentArts 观测插件以 **DSH 组合包（bundle）** 的形式安装进 DSH 的 profile，通过订阅 DSH 的会话事件与 `llm/stream` 拦截获取数据，**无需修改业务代码**。

数据流转过程：

```
DSH 运行时
  ├── 加载观测插件 bundle
  │     └── 订阅运行时事件
  │           ├── session/created · session/event · session/disposed   会话生命周期
  │           ├── turn/start · turn/end · step/start · step/end        回合与步骤
  │           ├── user/message · assistant/message                     消息内容
  │           ├── tool/call · tool/result                              工具调用
  │           ├── subagent/catalog                                    子 agent 名称
  │           └── llm/stream（拦截）                                  模型调用与流式响应
  │
  ├── Trace 数据 ──OTLP gRPC──→ APM（调用链）
  └── Metrics 数据 ──OTLP gRPC──→ AOM（指标）
                                         │
                                         ▼
                               AgentArts 观测平台展示
```

接入后，以下能力将被自动监控：

- **Agent 执行链路（invoke_agent）**：一轮对话的完整生命周期。
- **推理步骤（react step）**：每轮"模型推理 + 工具调用"的过程。
- **LLM 调用（chat）**：模型名称、Token 用量（含缓存读写）、输入/输出内容、首 Token 时延（TTFT）、每 Token 耗时（TBT）。
- **工具调用（execute_tool）**：工具名称、描述、输入参数、返回结果、执行耗时。
- **子 agent**：可串联到父 trace，并在 span 上带父会话标识。
- **业务指标**：Token 消耗、模型调用次数与耗时、工具/技能调用统计、会话数、响应成功率等。

## 接入步骤

### 步骤一：获取接入参数

1. 登录 [AgentArts 智能体平台](https://console.huaweicloud.com/agentarts/)。
2. 在左侧导航栏选择 **观测与优化 > 观测**。
3. 在"智能体列表"页面单击 **接入智能体**，填写名称并选择智能体类型，创建一个 DSH 智能体，获取各配置参数。

需要记录以下参数：

| 参数 | 说明 |
|---|---|
| 智能体 ID | AgentArts 智能体资源 ID |
| 账号 Domain ID | 账号 domain ID |
| 项目 ID | 华为云项目 ID |
| APM 上报地址 | 形如 `https://apm-access.<region>.myhuaweicloud.com` |
| APM 接入凭证 Token | 调用链上报凭证 |
| AOM 上报地址 | 形如 `https://aom-access.<region>.myhuaweicloud.com` |
| AOM 接入凭证 Access Code | 指标上报凭证 |
| AOM Prometheus 实例 ID | 指标实例标识 |

### 步骤二：安装插件

插件产物与安装脚本位于仓库的 `agentarts-instrumentation-dsh` 目录（发布包中为同目录下的
`huaweicloud-agentarts-observation-dsh-plugin-1.0.0.tgz` 与 `installer/` 脚本）。

安装脚本会自动完成三步：安装插件包 → 注册 bundle → 生成 `config.json`。

**Windows（PowerShell）**

```powershell
# 1. 进入产物目录（含 tgz 与脚本）
cd <产物目录>

# 2. 临时放开脚本执行权限（仅当前窗口有效，关闭即失效，不修改系统策略）
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

# 3. 安装到 desktop profile
.\installer\dsh-agentarts-plugin.ps1 -Profile desktop `
  -AgentId <your-agent-id> `
  -DomainId <your-domain-id> `
  -ProjectId <your-project-id> `
  -Endpoint https://apm-access.<region>.myhuaweicloud.com `
  -Token <your-apm-token> `
  -AomEndpoint https://aom-access.<region>.myhuaweicloud.com `
  -AomAccessCode <your-aom-access-code> `
  -AomPrometheusId <your-prometheus-id> `
  -AgentName <your-agent-name>
```

**Linux / macOS**

```bash
# 1. 进入产物目录
cd <产物目录>

# 2. 安装
./installer/dsh-agentarts-plugin.sh --profile desktop \
  --agent-id <your-agent-id> \
  --domain-id <your-domain-id> \
  --project-id <your-project-id> \
  --endpoint https://apm-access.<region>.myhuaweicloud.com \
  --token <your-apm-token> \
  --aom-endpoint https://aom-access.<region>.myhuaweicloud.com \
  --aom-access-code <your-aom-access-code> \
  --aom-prometheus-id <your-prometheus-id> \
  --agent-name <your-agent-name>
```

**其他安装方式**

- **DSH 插件界面**：打开 **Plugins** → **Add plugin**，选择本地目录或 `.tgz` 安装；安装后运行
  `configure` 子命令写入接入参数（见步骤三）。
- **CLI**（非 desktop profile）：

  ```bash
  dsh plugin --profile <profile> add "file:<产物目录>/huaweicloud-agentarts-observation-dsh-plugin-1.0.0.tgz"
  ```

**参数说明**

- 必填：智能体 ID、项目 ID、APM 上报地址、APM Token；启用 AOM 时还需 AOM 上报地址、Access Code、Prometheus ID。
- 上报地址不校验格式，以下写法都支持：`https://aom-access.<region>.myhuaweicloud.com`、
  `aom-access.<region>.myhuaweicloud.com:443`、`10.x.x.x:4317`（内网明文 gRPC）。
  缺少协议或端口时会按规则补全：域名补 `https://`，带端口按 443/其他区分 https/http，裸 IPv4 补 `:4317`。

| 参数（PowerShell / bash） | 是否必填 | 说明 |
|---|---|---|
| `-AgentId` / `--agent-id` | 是 | 智能体 ID |
| `-DomainId` / `--domain-id` | 否 | 账号 domain ID |
| `-ProjectId` / `--project-id` | 启用 AOM 时必填 | 华为云项目 ID |
| `-Endpoint` / `--endpoint` | 是 | APM 数据上报地址 |
| `-Token` / `--token` | 是 | APM 接入凭证 Token |
| `-AomEndpoint` / `--aom-endpoint` | 启用 AOM 时必填 | AOM 数据上报地址 |
| `-AomAccessCode` / `--aom-access-code` | 启用 AOM 时必填 | AOM 接入凭证 Access Code |
| `-AomPrometheusId` / `--aom-prometheus-id` | 启用 AOM 时必填 | AOM Prometheus 实例 ID |
| `-AgentName` / `--agent-name` | 否 | 智能体名称，写入 `gen_ai.agent.name` |
| `-ResourceType` / `--resource-type` | 否 | 智能体类型：`agent`（默认）、`multiagents`、`workflow` |
| `-ResourceVersion` / `--resource-version` | 否 | 资源版本，默认自动取运行中的 DSH 版本 |

**凭据安全建议**：不建议把 Token / Access Code 直接写在命令行（会进入 shell 历史与进程列表）。
脚本支持从环境变量读取：

```powershell
$env:DSH_AGENTARTS_APM_TOKEN = "<your-apm-token>"
$env:DSH_AGENTARTS_AOM_ACCESS_CODE = "<your-aom-access-code>"
# 然后省略 -Token / -AomAccessCode 参数，脚本会自动取用
```

### 步骤三：单独配置（适用于先用插件界面安装的场景）

如果插件已通过 DSH 插件界面或 `dsh plugin add` 安装，只需写入接入参数：

```powershell
.\installer\dsh-agentarts-plugin.ps1 configure -AgentId <id> -DomainId <id> -ProjectId <id> `
  -Endpoint https://apm-access.<region>.myhuaweicloud.com -Token <token> `
  -AomEndpoint https://aom-access.<region>.myhuaweicloud.com `
  -AomAccessCode <code> -AomPrometheusId <id>
```

`configure` 只写 `config.json`，不触碰 profile，安装与配置互不影响。

### 步骤四：重启 DSH

安装完成后必须重启 DSH 使插件生效（替换已安装的包尤其需要重启，以加载新的模块代）。

### 步骤五：验证数据上报

1. 查看插件日志，确认插件已加载：

   日志文件位置：

   ```
   # Windows
   %USERPROFILE%\.dsh\plugins\huaweicloud-agentarts-observation-dsh-plugin\data\logs\plugin-YYYY-MM-DD.log

   # Linux / macOS
   ~/.dsh/plugins/huaweicloud-agentarts-observation-dsh-plugin/data/logs/plugin-YYYY-MM-DD.log
   ```

   日志中出现以下内容说明插件已成功加载：

   ```
   [dsh-metrics] plugin starting, version: 1.0.0
   [dsh-metrics] config loaded: {... "apmEnabled":true, "aomEnabled":true}
   [dsh-metrics] APM (Traces) initialized {"endpoint":"https://apm-access.<region>.myhuaweicloud.com"}
   [dsh-metrics] AOM (Metrics) initialized {"endpoint":"https://aom-access.<region>.myhuaweicloud.com"}
   [dsh-metrics] plugin loaded successfully
   ```

   PowerShell 快速查看：

   ```powershell
   Get-Content (Get-ChildItem "$env:USERPROFILE\.dsh\plugins\huaweicloud-agentarts-observation-dsh-plugin\data\logs\*.log" | Sort-Object LastWriteTime | Select-Object -Last 1).FullName -Tail 20
   ```

2. 触发一轮 DSH 会话（发起对话并等待回答），一轮对话结束后插件会导出一批 trace。
   日志中出现以下行说明上报成功：

   ```
   [dsh-metrics] APM (Traces) exporting {"spanCount":9,...}
   [dsh-metrics] APM (Traces) export SUCCESS {"spanCount":9,...}
   ```

3. 进入 AgentArts 平台观测页面查看数据（见下一节）。

## 查看监控数据

1. 登录 [AgentArts 智能体平台](https://console.huaweicloud.com/agentarts/)。
2. 在左侧导航栏选择 **观测与优化 > 观测**。
3. 在"智能体列表"页面找到已接入的智能体，单击名称进入详情页面。

**查看业务指标**（指标分析页签）

- Tokens 消耗：Input Tokens 与 Output Tokens 消耗总量
- 模型调用次数与平均耗时
- 模型调用成功率
- 会话数、响应成功率
- 工具调用次数与耗时、技能调用统计

**查看调用链信息**（调用链分析页签）

- span 层级：`invoke_agent` → `react step` → `chat <model>` / `execute_tool <tool>`
- 各节点耗时与详细属性
- 单击 span 查看 Token 用量、缓存读写、TTFT、工具参数与结果等

**查看会话分析**（会话分析页签）

- 追踪对话上下文、统计 Token 消耗、定位异常问题

> 指标为周期性导出（约 60 秒一次），首轮数据可能需要等待一个周期才可见；
> 调用链在每轮对话结束后批量导出。

## 运行配置说明

配置文件位于 `~/.dsh/plugins/huaweicloud-agentarts-observation-dsh-plugin/config.json`，
支持 `//` 注释。主要字段见下，完整带注释的模板见仓库中的 `config.example.json`。

| 字段 | 说明 |
|---|---|
| `enabled` | 总开关，`false` 时不采集 |
| `otel.agentarts_agentops_otel_agent_apm_enable` | 是否上报调用链 |
| `otel.agentarts_agentops_otel_agent_aom_enable` | 是否上报指标 |
| `features.captureMessageContent` | 是否采集消息内容（默认 `true`，详见"安全与隐私"） |
| `features.linkSubagentTrace` | 是否把子 agent 串联到父 trace（默认 `true`） |
| `features.debug` | 是否输出 DEBUG 明细日志 |
| `features.logRetentionDays` | 日志保留天数（默认 14，`0` 关闭清理） |
| `user.id` | 用户标识，为空时取主机名 |

修改 `features.*` 与 `agent_name` 后**无需重启**（热生效）；修改 `otel`、`enabled`、
`outputDir`、`user.id` 需要重启 DSH。

## 常见问题

**插件未加载（日志中无 `[dsh-metrics]`）**

依次检查：

1. 确认 DSH 已重启（替换已安装的包必须重启才能加载新的模块代）。
2. 查看 profile 的 `dsh.profile.bundles` 是否包含 `huaweicloud-agentarts-observation-dsh-plugin`。
3. 查看 profile 的 `node_modules` 下是否存在该包目录。
4. 若在 DSH 插件界面看不到该插件，确认安装时选择了正确的 profile。

**Windows 提示"无法加载文件，因为在此系统上禁止运行脚本"**

执行安装脚本报 `UnauthorizedAccess`。在**同一个窗口**执行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

仅对当前窗口生效，无需修改系统级策略。若脚本是从网络下载的，还需先解除网络标记：
`Unblock-File .\dsh-agentarts-plugin.ps1`。

**安装后没有生成配置文件 / 插件提示 config warning [otel]: missing**

说明未写入接入参数。执行 `configure` 子命令（步骤三）补齐，然后重启 DSH。

**调用链无数据**

1. 确认 `agentarts_agentops_otel_agent_apm_enable` 为 `true`，且 APM 地址与 Token 已配置。
2. 确认本机能访问 APM 端点（可 `curl <endpoint>` 或 `Test-NetConnection <host> -Port 443` 验证）。
3. 确认已发起**实际对话**（一轮对话结束后才会导出；空转不会产生数据）。
4. 查看日志是否出现 `APM (Traces) export SUCCESS`。

**指标无数据**

1. 确认 `agentarts_agentops_otel_agent_aom_enable` 为 `true`。
2. 确认 AOM 地址、Access Code、Prometheus ID、项目 ID 四项均已配置。
3. 指标为 60 秒周期导出，等待一个周期后再查。
4. 若日志中连"导出尝试"都没有，说明该周期内没有记录到指标（无会话活动）。

**AOM 认证失败**

日志出现 `UNAUTHENTICATED` 或 `accesscode does not match the projectId`：

1. 确认 Access Code 与项目 ID 属于同一账号、同一实例。
2. 确认 Prometheus 实例 ID 正确。
3. 登录 AgentArts 平台重新获取最新凭证，重新执行 `configure` 并重启。

**日志出现 `DEADLINE_EXCEEDED` / `UNAVAILABLE`**

弱网环境下首次建链可能超时。插件已内置 30 秒超时与最多 3 次重试（退避 2s / 8s），
日志中看到 `export failed, retrying in 2000ms` 后跟 `SUCCESS` 属正常重试，数据不会丢失。
若持续出现 `export FAILED`，请检查网络与端点连通性。

**调用链中看不到 LLM 输入/输出内容**

1. 确认 `features.captureMessageContent` 为 `true`。
2. 若为 `false`，轨迹结构与性能指标仍会正常上报，只是不含消息、系统提示词、工具参数与结果文本。

**子 agent 与父对话不在同一条调用链**

子 agent 的 span 以父 turn 进行中的 root span 为父。若子 agent 在父 turn 结束后才启动，
会形成独立 trace（当前实现的已知边界）。此时仍可通过 span 上的 `dsh.session.parent_id`
属性按父会话过滤聚合。

**工具 span 上没有 `gen_ai.tool.description`**

工具描述来自 LLM 请求携带的工具定义。若该工具不在请求的 tools 列表中（或该轮未发起模型调用），
则不会上报该属性。

**导出的 trace 端口/协议不对**

上报地址支持多种写法，插件会按规则补全：已带 `http(s)://` 原样使用；带端口且端口为 443 用
`https://`、其他端口用 `http://`；无端口的域名补 `https://`；无端口的裸 IPv4 补 `:4317`（内网明文）。

## 安全与隐私

插件会把 DSH 运行时数据发送到 AgentArts。**默认会上报会话内容**：

| 类别 | 字段 |
|---|---|
| 会话内容 | `gen_ai.input.messages`、`gen_ai.output.messages` |
| 系统提示词 | `gen_ai.system_instructions` |
| 工具调用 | `gen_ai.tool.call.arguments`、`gen_ai.tool.call.result` |
| 设备标识 | `user.id`（未配置时取主机名） |
| 会话标识 | `gen_ai.session.id` |

如果会话中可能出现敏感信息，请把 `features.captureMessageContent` 设为 `false`
（热生效）：此后仍上报调用链结构与性能指标，但不含上述内容文本。

凭据以明文存储在 `config.json`，安装脚本会自动收紧文件权限（Windows 移除继承、
仅当前用户/SYSTEM/Administrators；Linux/macOS 为 `chmod 600`），并对历史备份做同样处理，
最多保留 5 份。更完整的安全说明见 [SECURITY-NOTES.md](../SECURITY-NOTES.md)。

## 卸载插件

```powershell
# Windows（卸载并保留配置文件，供日后重装复用）
.\installer\dsh-agentarts-plugin.ps1 uninstall -Yes -KeepConfig -Profile desktop

# 同时删除配置（默认备份后删除）
.\installer\dsh-agentarts-plugin.ps1 uninstall -Yes -Profile desktop
```

```bash
# Linux / macOS
./installer/dsh-agentarts-plugin.sh uninstall --yes --keep-config --profile desktop
```

卸载脚本会移除 bundle 注册与插件依赖，并按需处理 `config.json`；**不会自动重启 DSH**，
卸载完成后请手动重启使其生效。

也可以直接使用 DSH 的能力移除：在 **Plugins** 页卸载，或执行
`dsh plugin --profile <profile> remove huaweicloud-agentarts-observation-dsh-plugin`。

## 限制说明

- 调用链在**每轮对话结束后**批量导出，长对话过程中不会实时出现。
- 指标为 **60 秒周期**导出。
- 父 turn 结束后才启动的子 agent 不会串联到父 trace（见常见问题）。
- 上报端点必须网络可达；跨境或弱网环境建议确认链路质量。
